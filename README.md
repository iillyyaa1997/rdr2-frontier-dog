# Frontier Dog — «Пёс фронтира»

A dog companion for Red Dead Redemption 2 Story Mode, written from scratch: breeds with stats and innate traits,
pedigree / ordinary / ailing dogs, skills that grow with use, bonding like the horse, hunting help (fetch, drag, track,
point, flush), guarding, care, stables that sell, train, treat and buy dogs, a home for your dogs in camp, and delivery
by a rider wherever you are.

Status: in development (0.x). Inspired by Dog Companion by Shtivi; no code from it is used.

## Build

`./build.sh` (or `TEST=1 ./build.sh` for the test build) — clang-cl + lld-link in the `rdr2-msvc-build` Docker image with
the Microsoft CRT/SDK from xwin. Natives come from `src/sdk/natives.gen.h`, generated by `tools/gen_natives.py` from
[alloc8or/rdr3-nativedb-data](https://github.com/alloc8or/rdr3-nativedb-data). The import library for
ScriptHookRDR2.dll is generated at build time from the symbols the code imports, so no SDK files are needed.

## Requirements

- RDR2 1.0.1491.50 (Steam), Story Mode
- [ScriptHookRDR2 V2](https://www.nexusmods.com/reddeadredemption2/mods/1472) and an ASI loader
- Lenny's Mod Loader for the new items (dog reviver, food, treat) and the dog's core icon

## The dog's core icon

`data/hud/paw_core_0..15.png` — our own paw in the style of the game's core icons, 16 drained states like
`rpg_core_health core_state_0..15`, made by `tools/gen_paw_core.py` from the game's hearts (see its header). They are
packed into a texture dictionary `frontier_dog_hud.ytd` (textures `paw_core_0` … `paw_core_15`) with a Windows tool and
streamed by Lenny's Mod Loader; without it the core falls back to the game's paw blip. Not yet checked in game.
